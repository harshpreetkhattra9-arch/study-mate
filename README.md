# StudyMate - Student Study Planner

StudyMate is a beginner-friendly web application that helps students
organize their study tasks, manage priorities, and track their progress.

## Features

- Add study tasks with a subject, date, and priority.
- Mark tasks as completed or pending.
- Delete tasks when they are no longer needed.
- Filter tasks by completion status.
- View task statistics and completion percentage.
- Save tasks using browser localStorage.
- Responsive design for desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click index.html.
5. Select Open with Live Server.
6. Start adding your study tasks.

You can also open index.html directly in a browser for basic testing.

## How Data Is Stored

The application stores study tasks in the browser's localStorage.
No database or user account is required.

Tasks are stored locally and are not automatically synchronized
between browsers or devices.
